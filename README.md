# 📄 Documentação - Projeto Barbearia

## 🔹 Frontend (HTML, CSS, JavaScript)

### Descrição
Este projeto é uma aplicação web para gerenciamento de agendamentos em uma barbearia.

### Estrutura

- `index.html` - Estrutura principal da página.
- `styles.css` - Estilos personalizados.
- `scripts.js` - Scripts para manipulação do DOM e eventos.
- `image.png` - Imagem de fundo para estilização.

### Recursos

- Cadastro de Barbeiros
- Cadastro de Serviços
- Agendamento de Horários
- Exibição das informações em tabelas

### Tecnologias

- HTML5
- CSS3
- JavaScript

### Instruções de Uso

1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Use os botões de navegação para cadastrar barbeiros, serviços e agendar horários.

### Melhorias Sugeridas

- Persistir dados usando `LocalStorage` ou Backend.
- Melhorar responsividade.
